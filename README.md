# CodeAlpha Python Tasks

Python Programming Internship tasks completed for CodeAlpha.

## Task 1: Hangman Game
A text-based Hangman game in Python.
- Random word from 5 predefined words
- Maximum 6 wrong guesses
- Concepts used: random, while loop, if-else, strings, lists
- File: hangman.py

## Task 2: Stock Portfolio Tracker
A simple stock tracker that calculates total investment.
- Hardcoded stock prices using a dictionary (AAPL, TSLA)
- User enters stock name and quantity
- Displays total investment and saves it to portfolio.txt
- Concepts used: dictionary, input/output, arithmetic, file handling
- File: stock_tracker.py

## How to Run
python hangman.py
python stock_tracker.py
